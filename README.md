# Vehicle Parking Management System

A Java-based web application for managing vehicle parking operations.

## Technologies Used

- Java
- JSP
- Servlets
- JDBC
- MySQL
- Maven
- Apache Tomcat
- HTML
- CSS
- JavaScript

## Features

- Admin Login
- Vehicle Entry
- Automatic Parking Slot Allocation
- Vehicle Exit
- Parking Fee Calculation
- Payment Processing
- Parking Records
- Payment Records
- Parking Slot Management
- Available and Occupied Slot Tracking
- Dashboard Statistics
- Today's Revenue
