# Vehicle Parking Management System

A Java-based web application developed to manage vehicle parking operations, including vehicle entry and exit, parking slot allocation, parking fee calculation, payments, parking records, and dashboard monitoring.

## Features

- Admin Login and Authentication
- Vehicle Registration
- Vehicle Entry Management
- Vehicle Exit Management
- Vehicle Number Validation
- Vehicle Type Selection
- Automatic Parking Slot Allocation
- Available and Occupied Slot Tracking
- Automatic Parking Fee Calculation
- Cash, UPI, and Card Payment
- Parking Records
- Payment Records
- Parking Slot Management
- Dashboard Statistics
- Today's Revenue
- Real-time Parking Status Updates

## Technologies Used

- Java
- JSP
- Servlets
- JDBC
- MySQL
- Maven
- Apache Tomcat
- HTML
- CSS
- JavaScript
- NetBeans
